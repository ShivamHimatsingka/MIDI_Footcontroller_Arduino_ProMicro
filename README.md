# MIDI_Footcontroller_Arduino_ProMicro
This is the code for making a MIDI controller which sends PC and CC messages via USB on Arduino Pro Micro. The code can be used on any Arduino board with native USB compatibility (eg: Pro Micro, Leonardo).

How to use:
1) Connect 8 MOMENTARY switches to Pins 
2) Download MidiFootcontroller.ino and install Arduino IDE.
3) Connect your Arduino board to your computer.
4) Open MidiFootcontroller.ino in Arduino IDE.
5) Change the board in Arduino IDE to whichever board you have.
6) Upload the code.
